Samsara playback checklist

Cavern Cinema · doors 6:30 · film 7:00. Mac → HDMI → receiver → projector. Picture already works; sound over HDMI didn't.

1. Sound over HDMI

  1. System Settings → Sound → Output: pick the HDMI / receiver entry. [apple]
  2. Audio MIDI Setup (Applications → Utilities) → the HDMI device → Configure Speakers → 5.1 Surround → press Test on each speaker → Apply. [apple]
  3. No tones? On the receiver, check that it's on the Mac's HDMI input and that its audio output isn't set to the TV/projector.

2. If HDMI sound still fails: use a cable

  • Run a 3.5 mm headphone-jack cable from the Mac to an analog input on the receiver, then switch the receiver to that input for sound. In System Settings → Sound → Output, pick Headphones or External Headphones.
  • A cable adds no noticeable delay. Bluetooth is what can lag, so don't use it.
  • This is stereo, not 5.1. DCP-o-matic Player mixes 5.1 down to stereo when the output has two channels. [dcp-o-matic]

3. Play the DCP

  1. DCP-o-matic Player → Preferences → Sound: tick Play sound and pick the same output as above. [dcp-o-matic]
  2. System Settings → Displays → the projector: 1920×1080, 24 Hz. [jvc, apple]
  3. Open the Samsara DCP folder and press play.
  4. Watch the dropped-frames count at the bottom right. If it climbs: View → Decode at half resolution (or quarter). [dcp-o-matic]
  5. View → Full screen.

Pre-show loop

  1. Download samsara-2026-11-19.mp4 (8 MB, 90 s).
  2. Open it in QuickTime Player → View → Loop → play, full screen. [apple]

Samsara playback checklist

Cavern Cinema · doors 6:30 · film 7:00. Run through this on the real Mac, receiver and projector before doors.

1. Picture

  1. System Settings → Displays → the projector: 1920×1080, 24 Hz. [jvc, apple]

2. Sound

  1. System Settings → Sound → Output: the HDMI / receiver. [apple]
  2. Audio MIDI Setup → the HDMI device → Configure Speakers → 5.1 Surround → press Test on each speaker → Apply. [apple]
    No tones means the problem is on the receiver: check that it's on the Mac's HDMI input.

3. Play the DCP

  1. DCP-o-matic Player → Preferences → Sound: tick Play sound and pick the HDMI device. [dcp-o-matic]
  2. Open CS DISK/SAMSARA_FTR_F_LO-EN_51_2K_20231118_IOP_OV and press play.
  3. Watch the dropped-frames count at the bottom right. If it climbs: View → Decode at half resolution (or quarter). [dcp-o-matic]
  4. View → Full screen.

If the DCP won't play right

  • Studio ProRes file in QuickTime: download (89 GB, start it early). Sound uses the same steps as section 2.
  • Lighter DCP on CS DISK from about 5 pm: SAMSARA_100M_REENCODE_cs232. It plays the same way as section 3.
